Why these groupings: structural actions (edit / duplicate / reorder) sit first since they're the most frequent; style actions (copy/paste styles) are second and Paste styles is shown disabled when nothing's been copied yet, rather than hidden — so the option is discoverable even unused; Save as reusable block is isolated on its own because it's a bigger commitment (turns this into a shared component across pages); Delete is last, separated by a divider, and colored red — the one action that shouldn't be reachable by an accidental fast click.
