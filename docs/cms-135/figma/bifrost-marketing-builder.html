Marketing Pages — a Stage plugin for pages like this

Stage's default palette (Section, Grid, Card, Button) is built for content pages. Marketing and auth pages are composed of whole patterns — a split hero, a credentials form, a CTA band — so this plugin adds a second block set to Stage rather than making you assemble a login screen out of raw grids.
