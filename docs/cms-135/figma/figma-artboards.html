Marketing Pages — a Stage plugin for pages like this

Stage's default palette (Section, Grid, Card, Button) is built for content pages. Marketing and auth pages are composed of whole patterns — a split hero, a credentials form, a CTA band — so this plugin adds a second block set to Stage rather than making you assemble a login screen out of raw grids.

Right-click menu on canvas blocks

Right now selecting a block only opens the Inspector on the right — fine for style changes, but slow for structural moves (duplicate, reorder, delete) that you'd rather do at the cursor. Here's a right-click context menu on the Hero block from your landing page.

Why these groupings: structural actions (edit / duplicate / reorder) sit first since they're the most frequent; style actions (copy/paste styles) are second and Paste styles is shown disabled when nothing's been copied yet, rather than hidden — so the option is discoverable even unused; Save as reusable block is isolated on its own because it's a bigger commitment (turns this into a shared component across pages); Delete is last, separated by a divider, and colored red — the one action that shouldn't be reachable by an accidental fast click.
