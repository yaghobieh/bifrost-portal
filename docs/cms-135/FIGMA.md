## Files

Import these HTML frames with the **html.to.design** Figma plugin (or copy into a Figma file as frames):

1. `figma/figma-artboards.html` — both screens in one page (builder + context menu)
2. `figma/bifrost-marketing-builder.html` — Store card + Stage builder (library, canvas, inspector)
3. `figma/bifrost-context-menu.html` — right-click menu on a Hero block

## Plugin steps

1. Open a new Figma file named **Bifrost Marketing Pages 1.1.11**
2. Run **html.to.design**
3. Drop `figma-artboards.html`
4. Name frames: `01 Store + builder`, `02 Canvas context menu`

Spec: `BIFROST_MARKETING_BUILDER_SPEC.md`

Bear props: `BEAR_COMPONENT_PROPS.md`
